## Lesson 26 — んです and polite requests
どうして 遅{おく}れたんですか

1. pattern: 普通形{ふつうけい} ＋ んです
   gloss: Explaining, asking for an explanation, or setting up a request
2. pattern: Vて-form いただけませんか
   gloss: Could you possibly …? — more polite than て ください
3. pattern: 疑問詞{ぎもんし} ＋ Vた-form ら いいですか
   gloss: What / where / when should I …? — asking for advice
4. pattern: N(object)は 好{す}きです ／ 上手{じょうず}です ／ あります, etc.
   gloss: Fronting the object as topic with these predicates
